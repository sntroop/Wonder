# Безопасность

Это публичная клиентская часть Wonder. Она опубликована, чтобы код можно было
проверить: что приложение делает и чего оно не делает.

## Чего в коде нет

- загрузки и исполнения стороннего кода (dex/apk/so из сети);
- скрытых серверов, адресов и ключей;
- передачи куки, VK/SoundCloud/Spotify-токенов и любых данных аккаунта;
- чтения SMS, контактов, журнала звонков, камеры, микрофона и геолокации;
- доступа к внешнему хранилищу;
- телеметрии, аналитики и отправки логов.

Сетевой слой (`ApiClient`, `vk/*`, `spotify/*`) в этой версии — заглушки:
методы ничего не отправляют. Единственный HTTP-сервер — локальный
`127.0.0.1` внутри плеера, он отдаёт уже скачанный аудиофайл.

## Разрешения

`INTERNET`, `ACCESS_NETWORK_STATE`, `POST_NOTIFICATIONS`,
`FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `WAKE_LOCK` —
подробнее в README. Ничего сверх этого приложение не запрашивает.

## Как проверить сборку

```bash
cd android
./gradlew assembleDebug
apksigner verify --print-certs app/build/outputs/apk/debug/app-debug.apk
```

Проверить, что в APK нет неожиданных URL:

```bash
unzip -p app/build/outputs/apk/debug/app-debug.apk classes.dex | strings | grep -E "https?://"
```
